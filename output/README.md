# Output — Buyer Profiler

Completed profiles land here. One file per prospect.

## Naming Convention

`YYYY-MM-DD-[prospect-slug]-profile.md`

Examples:
- `2026-05-07-jane-smith-profile.md`
- `2026-05-14-acme-cfo-profile.md`

## What Goes Here

The full profile + close strategy output from a completed run. Save it here so you can reference it before the next call without re-running the transcript.
